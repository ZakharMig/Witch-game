# Witch Game v0.9 — Comic Forest and Living Environment

This update changes the **forest exterior** to a hand-painted, high-contrast 16:9 comic-style dark fantasy image: `art/forest_comic_v09.webp`, 1920 × 1080. It includes the cottage and path only; the witch, HUD and input controls are still drawn and controlled by Godot.

## New animations
- **Chimney smoke** is generated by `_draw_chimney_smoke()` in `game.gd`. Eleven softly shaded puffs rise from the chimney (around viewport x=866, y=91), drift horizontally and fade. It is a continuously animated effect, not baked into the background.
- **Foreground plants** are generated by `_draw_swaying_plants()` as animated leaves and grass. Their tips sway at different rates near both lower corners, drawn in front of the witch but below the HUD.
- Subtle moving ground haze remains.

## Preserved
- Four-direction beat-'em-up arena movement, jumping, magic and 16-frame witch animations.
- Slime AI, HP and XP, enemy combat, defeat/retry, cottage entry/exit, interior and healing.
- Door interaction aligned to the new background at (623, 461).

## iPad/Xogot test
Import `https://github.com/ZakharMig/Witch-game` (main) as a new project in Xogot, run, watch the **moving smoke and plants**, move in all directions, jump, cast, fight the slime, and enter the house using USE. The last reported working v0.8 is backed up at `backup/v0.8-working`.

**Art note:** the new exterior is one illustrated background (no parallax separation yet); foreground plants and chimney smoke are separate animated geometry. This is real in-game motion, not an animated video or baked-in screenshot. Needs iPad runtime verification.
