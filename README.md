# Witch Game — v0.2 (iPad / Xogot)

Godot 4.x 2.5D beat-'em-up RPG prototype.

## Controls

- iPad: four arrows (left, right, up, down), JUMP, CAST. Multi-touch supported.
- Keyboard: WASD / arrow keys to move; Space or K to jump; J to cast.
- Move in both X and Y on the arena. Jump height is separate from ground depth.
- Hit the slime from the same depth lane; three spells defeat it.

## How to try it in Xogot

Download or clone the **feature/arena-witch-v02** branch and open the project in Xogot. The original working **main** branch remains unchanged. The illustration in `art/witch.png` is a reduced-resolution prototype sprite; full animation frames are not implemented yet.

If Xogot asks to upgrade a Godot project, back it up first.
